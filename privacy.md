# VaultWorks Media Privacy Policy

Last updated: November 1, 2026

## About

VaultWorks Media is a personal, non-commercial
application used to access Google Drive media
through rclone and a private Jellyfin server.

## Google Drive Access

The application requests read-only access to
Google Drive.

It accesses media files available to the dedicated
VaultWorks Google account, including media shared
with that account.

The application cannot modify or delete files
in Google Drive.

## Data Storage

Media files may be temporarily cached on the
owner's private server.

Jellyfin may store media metadata and viewing
history locally.

OAuth credentials are stored on the private server.

## Data Sharing

Google Drive data is not sold or shared with
advertisers or analytics providers.

Media is streamed only to authorized users.

## Revoking Access

Google Drive access can be revoked through
Google Account security settings.
