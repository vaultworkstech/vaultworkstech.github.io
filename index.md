# VaultWorks Media

VaultWorks Media is a personal, non-commercial application
used to connect a private Jellyfin media server to Google Drive.

The application uses rclone to access media files shared
with a dedicated Google account.

Google Drive access is read-only. The application cannot
upload, modify, or delete files.

Media is accessed privately through the owner's server.
